# Bank Account System

A simple Java console application that simulates basic banking operations.

## Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account balance
* Prevent overdraft transactions

## Concepts Used

* Classes & Objects
* Encapsulation
* Constructors
* Methods
* Conditional Statements

## Files

* `BankAccount.java`
* `BankAccountSystem.java`

## Sample Operations

* Deposit ₹5000
* Withdraw ₹2000
* Check Balance
* Handle insufficient funds

## Future Enhancements

* Multiple accounts
* Transaction history
* PIN authentication
