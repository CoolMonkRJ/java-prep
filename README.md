# 📌 About

This repository contains beginner to intermediate Java projects focused on learning:

- Core Java
- Object-Oriented Programming
- Collections Framework
- File Handling
- Exception Handling
- Java Fundamentals
- Clean Code Practices

Each project is built independently to practice real-world programming concepts.

# 🚀 Projects

| No. | Project | Description |
|-----|----------|-------------|
| 01 | 🎓 Student Management System | CRUD operations using OOP |
| 02 | 🏦 Bank Account System | Deposit, Withdraw & Balance Management |
| 03 | 📊 Frequency Counter | Count occurrences using HashMap |
| 04 | 🔄 Reverse String & Palindrome | String manipulation practice |
| 05 | 📈 Sorting Algorithms | Bubble Sort & Selection Sort |
| 06 | 📦 Inventory Management System | Product inventory using OOP |
| 07 | 💳 ATM Simulation | Banking transaction simulation |
| 08 | 📄 File Reader & Word Counter | Java File Handling |
| 09 | 📝 Student Grade Calculator | Grade calculation based on marks |
| 10 | 📉 Trade Logger | Console-based trade logging system |
