# Student Management System

A simple Java console-based application to manage student records using Object-Oriented Programming principles.

## Features

* Add students
* Store student details (ID, Name, Marks)
* Display all students
* Find the top-scoring student

## Concepts Covered

* Classes and Objects
* Encapsulation
* Constructors
* ArrayList
* Loops
* Methods
* Object-Oriented Programming (OOP)

## Project Structure

```text
src/
├── Student.java
├── StudentManager.java
└── Main.java
```

## Example Output

```text
All Students:
Student{id=1, name='Rohit', marks=88.0}
Student{id=2, name='Aman', marks=92.0}
Student{id=3, name='Priya', marks=85.0}

Top Scorer:
Student{id=2, name='Aman', marks=92.0}
```

## Classes

### Student

Represents a student with:

* ID
* Name
* Marks

### StudentManager

Handles:

* Adding students
* Displaying students
* Finding the top scorer

### Main

Application entry point used to test the functionality.

## Learning Outcomes

After completing this project, you will understand:

* How to create custom classes
* How to use ArrayList to store objects
* How to iterate through collections
* How to design simple OOP-based applications
* How to separate business logic from data models
